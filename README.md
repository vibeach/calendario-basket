# Calendario Storico Superbasket

Un evento al giorno dall'archivio storico della pallacanestro italiana - 5.680 eventi, dal 1891 al 2026.

Live: https://vibeach.github.io/calendario-basket/

Dati: compleanni giocatori/allenatori, trofei vinti, anniversari, ricordi storici - dall'archivio Superbasket (200.000 pagine digitalizzate).
